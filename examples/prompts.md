## 💡 提示词编写技巧

### 1. 基础要素

一个优秀的提示词应该包含：

```
主体描述 + 场景设定 + 风格要求 + 质量描述
```

**示例分解**:
```
主体: 一只毛茸茸的橘色猫咪
场景: 坐在阳光下的窗台上，背景是温馨的室内
风格: 动漫风格
质量: 高质量，4K分辨率
```

### 2. 细节描写

**添加细节可以提升效果**:
- 动作：坐在、站立、奔跑、飞翔
- 光线：阳光、自然光、侧光、逆光、柔光
- 情绪：可爱、温馨、宁静、活力
- 时间：清晨、傍晚、午后、深夜
- 季节：室内、户外、自然、城市

### 3. 风格关键词

**常用风格关键词**:
- 动漫风格: "动漫风格"、"日式动漫"、"新海诚风格"
- 写实风格: "照片级质量"、"自然光"、"商业摄影"
- 艺术风格: "油画"、"水彩画"、"印象派"、"抽象画"
- 简约风格: "极简主义"、"扁平化"、"单色"
- 未来风格: "赛博朋克"、"科技感"、"未来主义"

### 4. 质量关键词

**质量关键词**:
- "高清"、"4K"、"细节丰富"、"专业摄影"
- "电影质感"、"广告级"、"杂志封面"
- "精细构图"、"完美光线"

## 🎯 不同场景的提示词模板

### 人物肖像

```
[性别][年龄]肖像，[表情]表情，[穿着]，[背景]，[风格]，[质量]
```

**示例**:
```
25岁女性肖像，微笑表情，穿着白色连衣裙，海边风景，自然光，动漫风格，高质量
```

### 风景描述

```
[时间][地点]，[天气]，[主体]，[动作]，[风格]，[质量]
```

**示例**:
```
傍晚的海边，晴天，海浪拍打礁石，慢动作，唯美，电影质感
```

### 抽象概念

```
[概念]，[颜色]，[风格]，[构图]，[质量]
```

**示例**:
```
自由与希望，蓝白配色，抽象画，中心构图，4K高清
```

## ⚠️ 常见错误

### 避免的问题

1. **提示词过短**:
   ❌ "猫"
   ✅ "一只可爱的橘色猫咪，坐在阳光下"

2. **信息冲突**:
   ❌ "黑暗中的明亮的房间"
   ✅ "黄昏时分，房间里有温暖的灯光"

3. **描述模糊**:
   ❌ "漂亮的花"
   ✅ "盛开的粉色玫瑰，花瓣上有露珠"

4. **缺少风格**:
   ❌ "一个人在看书"
   ✅ "优雅的阅读场景，极简主义风格，温馨氛围"

5. **质量描述缺失**:
   ❌ "风景画"
   ✅ "壮丽的山川风景，4K分辨率，细节丰富"

## 🎓 进阶技巧

### 使用AI生成提示词

如果不确定如何描述，可以先用AI生成描述，再优化：

```
请帮我描述一个：一只可爱的猫咪在阳光下睡觉的场景
```

### 参考优秀作品

从电影、动漫、摄影作品中提取关键元素：
- 色彩搭配
- 构图方式
- 光线处理
- 细节描绘

### 迭代优化

1. 先用简单提示词测试
2. 根据结果调整关键词
3. 逐步添加细节
4. 多次尝试找到最佳效果
